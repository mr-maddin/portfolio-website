# 📸 Portfolio Website – Martin

Eine minimalistische und elegante Portfolio-Website für meine Fotografie.  
Die Seite präsentiert meine Arbeiten in einer Galerie, enthält Informationen über mich und bietet eine einfache Möglichkeit zur Kontaktaufnahme.  
Sie wurde ohne Frameworks ausschließlich mit **HTML**, **CSS** und **JavaScript** entwickelt, um den Fokus auf sauberen Code und Lernfortschritt zu legen.
